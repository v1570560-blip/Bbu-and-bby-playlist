A private, romantic digital love memory book and soundtrack player built for Bbu and bby. This application combines a cozy hand-painted 2D anime aesthetic with an interactive music engine and a searchable love note wall.
✨ Features
Hero Sanctuary: Full viewport-height opening screen featuring the couple portrait, subtle floating particle physics, and soft cinematic lighting.
Curated 24-Track Love Soundtrack:
Integrated audio streaming for all 24 curated romantic tracks.
Interactive playback deck with scrubber, duration timer, repeat/loop, and shuffle modes.
Auto-play next track on song completion.
Floating mini-player and quick ♫ Song List drawer with live search.
Love Message Wall ("Leave a little love here 💌"):
Heartfelt note submission for couples with sender and partner name fields.
Enforced single-note-per-device rule to keep notes meaningful.
Interactive like reactions and timestamp formatting.
Find a Love Message 🔎:
Live query search allowing users to find notes by either partner's name or both simultaneously.
Responsive & Mobile-First:
Optimized for Android, iOS, tablets, and desktop displays.
Supports PWA "Add to Home screen" for instant standalone app experience on mobile devices.

🛠️ Tech Stack
Framework: React 19 + TypeScript
Bundler / Tooling: Vite
Styling: Tailwind CSS
Icons: Lucide React
Audio / Media: YouTube IFrame API Integration
Storage Layer: LocalStorage with modular database interface
🚀 Getting Started
Prerequisites
Node.js (v18 or higher recommended)
npm or yarn
Installation & Local Run
Clone the repository:
code
Bash
git clone https://github.com/your-username/bbu-and-bby.git
cd bbu-and-bby
Install dependencies:
code
Bash
npm install
Start the local development server:
code
Bash
npm run dev
Open http://localhost:3000 in your browser.
Building for Production
code
Bash
